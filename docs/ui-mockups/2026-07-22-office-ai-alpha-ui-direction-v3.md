# Office AI Alpha UI V3：高级极简精修

## 目标

V3 继承 V2 的全部易用性与功能边界，只提升视觉完成度。高级感通过字体、比例、网格、留白和表面细节实现，不增加任何操作负担。

## 不变项

- 用户导航仍为：首页、任务、文件、模板。
- 首页仍为三选一和一个“继续”按钮。
- 确认页仍为四步流程和一个“开始生成”按钮。
- 结果页仍以文件下载为首要内容，其余信息折叠。
- 管理台仍以异常事项为主，不恢复密集图表。
- 不出现紫色、渐变、发光 AI 图形、聊天框或内部 AI 术语。

## 视觉精修

- 风格：Premium Swiss Minimalism。
- 背景：暖调瓷白 `#F7F8F6`，内容面使用纯白。
- 文字：深墨色 `#020617`，Primary Action 使用钢蓝 `#075985`。
- 字体：Noto Sans SC，标题使用更紧凑的字距与 600–700 字重。
- 网格：12 栏基础网格，8px spacing rhythm，内容边缘严格对齐。
- 组件：12px 圆角、1px 冷灰边框、极轻的中性阴影。
- 图标：统一 1.5px 线性图标，使用小型浅色图标容器增强精致度。
- 状态色仅用于成功、提醒与错误，不作为装饰。

## 成功标准

- 第一眼比 V2 更精致，但操作路径和信息数量没有增加。
- 四张图保持相同导航、字体、按钮、圆角与表面语言。
- 每张用户端页面仍只有一个实心 Primary Action。
- 无紫色、无彩色渐变、无发光效果、无卡片墙。
